# Astronomical Scene Engine

A single, offline web page for flying the Solar System: standing on other worlds, watching eclipses, transits and meteor showers, and stepping back to old world views and deep time. Positions come from published orbits and data, and the page says what is measured, computed, modelled or invented.

**Open it:** https://andrelouw3.github.io/astronomy-scene-engine/

Free, with no tracking. Everything is in the one `index.html`: it makes no network requests and works offline once saved.

This repository only holds the built page. The source is private. Third-party licences and data credits are in [LICENSE-THIRD-PARTY.md](LICENSE-THIRD-PARTY.md).
